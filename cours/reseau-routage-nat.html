🗺️Routage et NAT

Comment un paquet trouve son chemin entre les réseaux, et comment des centaines de PC sortent sur Internet avec une seule IP publique.

La passerelle par défaut

Quand un PC veut joindre une IP hors de son réseau, il envoie le paquet à sa passerelle (le routeur). Sans passerelle : pas d'Internet !

Le PC .10 a pour passerelle 192.168.1.1 : c'est l'interface du routeur dans son réseau.

La table de routage

Chaque routeur a une table : « pour aller vers ce réseau, je passe par là ».

Réseau destinationProchain sautInterface
192.168.1.0/24Directement connectéG0/0
192.168.2.0/24Directement connectéG0/1
10.0.0.0/8172.16.0.2S0/0
0.0.0.0/0Box du FAIG0/2
0.0.0.0/0 = route par défaut : utilisée quand aucune autre route ne correspond (en général, vers Internet). Si plusieurs routes correspondent, le routeur prend la plus précise (le plus grand /).

Deux façons de remplir la table

✍️ Routage statique

L'administrateur écrit les routes à la main.

  • ✅ Simple, prévisible, sûr
  • ❌ Ne s'adapte pas si un lien tombe
  • 👉 Petits réseaux

🤖 Routage dynamique

Les routeurs s'échangent leurs routes avec un protocole.

  • ✅ S'adapte tout seul aux pannes
  • ❌ Plus complexe à configurer
  • 👉 Réseaux moyens et grands
ProtocolePrincipeÀ retenir
RIPCompte le nombre de sauts (routeurs traversés)Simple, max 15 sauts, ancien
OSPFCalcule le meilleur chemin selon le débit des liensLe plus utilisé en entreprise
BGPRelie les grands réseaux entre euxLe protocole d'Internet

Commandes utiles

# Cisco : route statique puis route par défaut R1(config)# ip route 10.0.0.0 255.0.0.0 172.16.0.2 R1(config)# ip route 0.0.0.0 0.0.0.0 203.0.113.1 R1# show ip route # Windows / Linux : voir la table de routage du PC C:\> route print $ ip route

Le problème

Les adresses privées (192.168…, 10…) ne circulent pas sur Internet. Et il n'y a pas assez d'IPv4 publiques pour tout le monde.

La solution : le NAT

Le routeur remplace l'IP privée source par son IP publique à la sortie, et fait l'inverse au retour. Il garde une table de traduction.

Côté LAN (privé)Côté Internet (public)
192.168.1.10 : 51000➡️203.0.113.5 : 51000
192.168.1.11 : 51000➡️203.0.113.5 : 51001
192.168.1.12 : 49152➡️203.0.113.5 : 49152
1️⃣

NAT statique

1 IP privée ↔ 1 IP publique, toujours la même.

👥

PAT (NAT overload)

Plusieurs IP privées partagent une seule IP publique, on les distingue par le port. C'est ce que fait ta box !

🚪

Redirection de port

Pour rendre un serveur interne joignable : « ce qui arrive sur le port 443 public → envoie au serveur 192.168.1.50 ».

IPv6 a assez d'adresses (128 bits) pour se passer de NAT : chaque appareil peut avoir une adresse publique.
