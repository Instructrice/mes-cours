Les rôles d'un serveur Windows, l'annuaire Active Directory, les GPO et les droits sur les partages.

Windows Server : un serveur, plusieurs rôles

On installe des rôles depuis le Gestionnaire de serveur (ou PowerShell).

📇

AD DS

L'annuaire Active Directory : comptes, groupes, ordinateurs.

📖

DNS

Indispensable à l'AD : les PC trouvent le contrôleur de domaine grâce au DNS.

📬

DHCP

Distribue les adresses IP aux postes.

📁

Serveur de fichiers

Dossiers partagés pour les services.

🖨️

Impression

Gère les imprimantes partagées.

🔄

WSUS

Centralise les mises à jour Windows.

PS C:\> Install-WindowsFeature AD-Domain-Services -IncludeManagementTools PS C:\> Get-WindowsFeature | Where Installed

Le vocabulaire de l'AD

🏰

Domaine

Ensemble d'objets gérés ensemble, ex : entreprise.local. Une connexion = un seul compte pour tous les postes.

🖥️

Contrôleur de domaine (DC)

Le serveur qui héberge l'annuaire et authentifie les utilisateurs. On en met au moins 2.

🌳

Arbre et forêt

Plusieurs domaines liés forment un arbre ; plusieurs arbres, une forêt.

🗂️

Unité d'organisation (UO)

Un « dossier » dans l'AD pour ranger les objets (par service, par site) et y appliquer des GPO.

Deux couches de droits

🌐 Droits de partage

S'appliquent quand on accède par le réseau (\\SRV\Compta). Lecture, Modifier, Contrôle total.

💾 Droits NTFS

S'appliquent toujours, en local comme en réseau. Plus fins : lecture, écriture, modification, contrôle total…

La règle : par le réseau, c'est le droit le plus restrictif des deux qui s'applique. Partage « Contrôle total » + NTFS « Lecture » = Lecture.

Bonne pratique : AGDLP

  1. Accounts : les comptes utilisateurs…
  2. … vont dans des groupes Globaux (par métier : GG_Compta)…
  3. … qui vont dans des groupes Domaine Locaux (par ressource : GDL_Compta_RW)…
  4. … qui reçoivent les Permissions sur le dossier.

Résultat : on ne donne jamais de droits à un utilisateur directement. Un nouvel employé ? On l'ajoute juste au bon groupe.

Refuser l'emporte sur Autoriser en NTFS. À utiliser avec prudence.
