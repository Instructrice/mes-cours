🐧Linux : les commandes essentielles

L'arborescence Linux et les commandes que tu utiliseras tous les jours sur un serveur Debian ou Ubuntu.

Tout est fichier, tout part de /

Pas de C: sous Linux : une seule arborescence qui commence à la racine /.

/

La racine : tout part d'ici

/home

Dossiers des utilisateurs (/home/alice)

/root

Dossier de l'administrateur root

/etc

Fichiers de configuration

/var/log

Les journaux (logs)

/bin, /usr/bin

Les programmes (commandes)

/tmp

Fichiers temporaires, vidé au redémarrage

/dev

Les périphériques (disques : /dev/sda)

Chemins absolus et relatifs

Absolu

Part de la racine : /home/alice/cours

Relatif

Part de là où je suis : cours/, ../bob

. = dossier actuel · .. = dossier parent · ~ = mon dossier personnel. Les fichiers qui commencent par . sont cachés.
Linux est sensible à la casse : Fichier.txt et fichier.txt sont deux fichiers différents.

📂 Se déplacer

pwdOù suis-je ?
ls -lLister en détail (ls -la : + fichiers cachés)
cd /etcAller dans /etc (cd .. : remonter, cd ~ : chez moi)

📄 Fichiers

mkdir projetCréer un dossier
touch notes.txtCréer un fichier vide
cp a.txt b.txtCopier
mv a.txt doc/Déplacer ou renommer
rm fichierSupprimer (rm -r : un dossier) ⚠️ pas de corbeille

👀 Lire et chercher

cat fichierAfficher le contenu
nano fichierModifier avec un éditeur simple
tail -f /var/log/syslogSuivre un log en direct
grep "erreur" app.logChercher un mot dans un fichier
find / -name "*.conf"Trouver des fichiers

⚙️ Système

sudo commandeExécuter en administrateur
apt update && apt upgradeMettre à jour (Debian/Ubuntu)
apt install apache2Installer un paquet
systemctl status sshÉtat d'un service (start, stop, restart, enable)
ps aux / topVoir les processus
df -hEspace disque
ip aAdresses IP
Astuces : Tab complète automatiquement · ↑ rappelle la commande précédente · man ls affiche l'aide · Ctrl+C arrête une commande.

Installer un serveur web en 4 commandes

alice@srv:~$ sudo apt update alice@srv:~$ sudo apt install apache2 alice@srv:~$ sudo systemctl enable --now apache2 alice@srv:~$ systemctl status apache2 ● apache2.service - The Apache HTTP Server Active: active (running)

Les redirections et le pipe

SymboleEffetExemple

Se connecter à un serveur à distance

$ ssh alice@192.168.1.20 $ scp rapport.pdf alice@192.168.1.20:/home/alice/ # copier un fichier
Le prompt te renseigne : alice@srv:~$ = utilisateur normal · root@srv:~# = root, attention à ce que tu tapes !
