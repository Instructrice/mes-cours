🔢Adressage IPv4 et sous-réseaux

Lire une adresse IP, comprendre le masque, trouver le réseau, le broadcast et le nombre d'hôtes.

Une adresse IPv4 = 32 bits

Elle s'écrit en 4 octets (4 nombres de 0 à 255) séparés par des points : 192.168.1.10

🏠

Partie réseau

Identifie le réseau (comme le nom de la rue). Tous les PC d'un même réseau ont la même.

🚪

Partie hôte

Identifie la machine dans ce réseau (comme le numéro de la maison).

C'est le masque qui dit où s'arrête la partie réseau. Les bits à 1 = réseau, les bits à 0 = hôte.

Adresses privées (RFC 1918)

Utilisées dans les réseaux locaux, jamais routées sur Internet. Pour sortir, il faut le NAT.

Les classes A, B, C sont historiques (avant 1993). Aujourd'hui on utilise la notation CIDR (/24…), mais le vocabulaire reste utilisé.

La méthode en 4 étapes

  1. Nombre d'hôtes = 2(32 − CIDR) − 2 (on enlève adresse réseau et broadcast).
  2. Taille du bloc = 256 − valeur du masque dans l'octet « intéressant ». Ex : /26 → 256 − 192 = 64.
  3. Adresse réseau = le multiple du bloc juste en dessous de l'IP. Ex : 77 → 64.
  4. Broadcast = adresse réseau suivante − 1. Ex : 128 − 1 = 127.
Exemple : 192.168.10.77/26 → réseau 192.168.10.64, hôtes de .65 à .126, broadcast 192.168.10.127, 62 hôtes.
