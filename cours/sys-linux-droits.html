🔐Linux : utilisateurs et droits

Créer des comptes et des groupes, lire et modifier les droits rwx, et comprendre chmod 755.

Utilisateurs et groupes

👑

root

Le super-administrateur (UID 0). Il a tous les droits. On évite de travailler en root : on utilise sudo.

🙋

Utilisateurs

Chaque personne a son compte, son UID et son dossier dans /home.

👥

Groupes

On donne des droits à un groupe (ex : compta) plutôt qu'à chaque utilisateur.

Les fichiers qui stockent les comptes

FichierContenu
/etc/passwdLa liste des comptes (nom, UID, dossier, shell)
/etc/shadowLes mots de passe hachés (lisible par root uniquement)
/etc/groupLes groupes et leurs membres

Les commandes

# adduser alice # créer un utilisateur (interactif) # passwd alice # changer son mot de passe # groupadd compta # créer un groupe # usermod -aG compta alice # ajouter alice au groupe (-a = sans retirer les autres !) # usermod -aG sudo alice # donner les droits sudo # deluser alice # supprimer $ id alice ; groups alice # vérifier

Lire un ls -l

$ ls -l -rwxr-x--- 1 alice compta 4096 nov. 5 rapport.sh

Type

- fichier · d dossier · l lien

u · propriétaire

Ici alice : lire, écrire, exécuter.

g · groupe

Ici compta : lire et exécuter.

o · les autres

Tous les autres : aucun droit.

Que veut dire r, w, x ?

DroitValeurSur un fichierSur un dossier
r read4Lire le contenuLister le contenu (ls)
w write2ModifierCréer / supprimer des fichiers dedans
x execute1Exécuter (script, programme)Entrer dedans (cd)

Calculateur de droits

Coche les cases : on additionne r=4, w=2, x=1 pour chaque catégorie.

r (4)w (2)x (1)
OctalSymboliqueCommande

Les valeurs classiques

755

rwxr-xr-x · scripts, dossiers web

644

rw-r--r-- · fichiers classiques

700

rwx------ · dossier privé

600

rw------- · clé SSH privée

$ chmod 750 rapport.sh # en octal $ chmod u+x script.sh # ajouter x au propriétaire $ chmod o-r secret.txt # retirer r aux autres # chown alice:compta rapport.sh # changer propriétaire et groupe # chown -R www-data /var/www # -R = récursif
Jamais de chmod 777 « pour que ça marche » : tout le monde pourrait modifier le fichier. Applique le principe du moindre privilège.
